SysMate
=======

A Windows system information and monitoring tool built with MFC
and Visual C++ 6.0.

Features
--------

* Process viewer: running processes, search and tree navigation.
* Window viewer: top-level and child windows for each process.
* Network viewer: active TCP and UDP connections through SNMP.
* COM viewer: running OLE and COM objects.
* Performance monitor: CPU and memory graphs for Windows NT and 9x.
* Registry browser.
* File version information.

Building
--------

Open src\SysMate.dsw in Visual C++ 6.0 and build the project.
